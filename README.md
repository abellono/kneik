# Kneik

A *kneik* is Norwegian for a short, steep kick of a hill. This is a map of 37 of
them in western Oslo — every paved climb whose Strava KOM stands at under 20
seconds, at 1 % average grade or more — with the estimated watts it takes to
take each crown, how contested it is, and a campaign tracker kept in your
browser.

**Live: https://abellono.github.io/kneik/**

Segment data from the Strava API (public segment stats), surfaces verified
against OpenStreetMap. The reference point distances are measured from is
privacy-fuzzed to a ~500 m grid. Watts assume an 83 kg rider+bike at steady
KOM pace (CdA 0.32, Crr 0.004) — run-in momentum not modelled, so fast
approaches need less than shown.
